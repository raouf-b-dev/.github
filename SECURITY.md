# Security Policy

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report privately:

1. **Email**: [rbdz@hotmail.fr](mailto:rbdz@hotmail.fr)
2. **Subject**: `[SECURITY] <repository-name>: Brief description`
3. **Include**: description, steps to reproduce, potential impact, and a suggested fix if you have one

You may also use [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) when it is enabled on the repository.

### Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 5 business days
- **Fix or mitigation**: Depends on severity
