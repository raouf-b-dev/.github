# .github

Default [community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for public repositories under [raouf-b-dev](https://github.com/raouf-b-dev).

GitHub uses these files for any repository on the account that does **not** define its own copy of the same file.

## Files

| File | Applies when a repo has no… |
| :--- | :-------------------------- |
| `pull_request_template.md` | Own pull request template |
| `.github/ISSUE_TEMPLATE/bug_report.md` | Own bug-report issue template |
| `.github/ISSUE_TEMPLATE/feature_request.md` | Own feature-request issue template |
| `CONTRIBUTING.md` | Own contributing guide |
| `SECURITY.md` | Own security policy |

A repository that already ships one of these files keeps its own version; only the missing ones fall back to this repo.
